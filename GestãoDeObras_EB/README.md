# Sistema de Gestão de Obras

Este projeto é um portal web desenvolvido para facilitar a gestão de obras, permitindo o envio de arquivos CSV que são processados e inseridos automaticamente em um banco de dados (SGBD). O sistema visa simplificar o controle de projetos de construção, manutenção ou reformas, centralizando dados em uma plataforma acessível e eficiente.

---

## Funcionalidades

- **Envio de arquivos CSV:** Permite que usuários façam o upload de planilhas de obras, incluindo cronogramas, custos, materiais e encargos.
- **Processamento automático:** Os dados enviados são validados e convertidos para alimentar um banco de dados relacional.
- **Visualização e gerenciamento:** Após o upload, os dados podem ser visualizados, filtrados e gerenciados via interface web (dependendo da implementação futura).

---

## Tecnologias utilizadas

- **Backend:** (exemplo, Python Flask, Node.js, PHP, etc.)
- **Frontend:** HTML, CSS, JavaScript
- **Banco de Dados:** MySQL, PostgreSQL, SQLite, ou outro SGBD a sua escolha
- **Processamento:** Biblioteca para leitura de CSV (ex: pandas em Python)

---

## Como usar

1. Clone este repositório ou faça upload dos arquivos no seu servidor.
2. Configure seu banco de dados e ajuste as credenciais no arquivo de configuração.
3. Acesse o sistema via navegador.
4. Faça o upload do arquivo CSV através da interface.
5. Os dados serão inseridos automaticamente na sua base de dados.
